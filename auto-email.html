จับคู่แบบตรงตัวอักษร: หัวข้อหรือเนื้อหามี keyword ทั้งคำตามที่พิมพ์ (ไม่สนใจช่องว่างหัวท้ายบรรทัด, ตัวพิมพ์เล็กใหญ่ต้องตรง) และประเทศของแถวนั้นถูกเลือกไว้ในกฎที่เปิดอยู่ ถ้าตรงหลายกฎ ใช้กฎบนก่อน แถวมาเลเซียมีคำว่า «ขอใบกำกับภาษี» แต่กฎใบกำกับภาษีเลือกเฉพาะไทย จึงไม่ขึ้นปุ่ม จนกว่าจะเลือกมาเลเซียในกฎนั้นMatching is exact: the subject or body must contain a keyword as written (line edges are trimmed; letter case matters) and that row’s country must be selected on an enabled rule. If several rules match, the upper one wins. The Malaysia row contains “ขอใบกำกับภาษี”, but the tax-invoice rule selects only Thailand, so it stays unmatched until Malaysia is selected on that rule.
