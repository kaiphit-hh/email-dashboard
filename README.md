# email-dashboard

Static GitHub Pages dashboard for the team's email summaries.

## Auto Email (`auto-email.html`)

Standalone page where the accounting team keeps keyword rules for the **ดราฟอีเมล** (draft email) button. It is separate from `accounting.html`, which is regenerated by another job.

Rules are stored in this browser's `localStorage`, and can be exported or imported as JSON so they can move to a shared store later. The inbox on the page is sample data. The draft button only previews what would happen: it does not connect to Gmail and does not send mail.

Next step: keep the rules in a Google Sheet via Apps Script, and create the draft in the signed-in person's own Gmail (still unsent).
