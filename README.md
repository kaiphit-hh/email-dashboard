# email-dashboard

Static GitHub Pages dashboard for the team's email summaries.

## Auto Email (`auto-email.html`)

Standalone page where the accounting team keeps keyword rules for the **ดราฟอีเมล** (draft email) button. It is separate from `accounting.html`, which is regenerated by another job.

Until `WEB_APP_URL` at the top of `auto-email.html` is set, rules stay in this browser's `localStorage` and the draft button only previews. It does not call Gmail and does not send mail.

To share rules on a Google Sheet and create an unsent reply draft in the clicker's own Gmail, deploy `apps-script/` and paste the web app `/exec` URL into that constant. The steps are in [apps-script/README.md](apps-script/README.md).
